# Mayo AR Human Body — ชุดต้นแบบสำหรับ GitHub Pages

ชุดนี้ต่อยอดจาก repository `mudee-sudo/mayo-ar` โดยคงโมเดลเดิม `heart.glb` ไว้ที่โฟลเดอร์หลัก (root) เพื่อไม่ต้องย้ายไฟล์เดิม

## สิ่งที่มีในชุดนี้
- หน้าแรกและเมนูนำทาง
- แสดงหัวใจ 3 มิติด้วย `<model-viewer>` หมุน/ซูมได้
- ปุ่ม AR ผ่าน Scene Viewer / WebXR บนอุปกรณ์ที่รองรับ
- โครงสร้าง Image AR ด้วย MindAR
- บทเรียนพื้นฐานเรื่องหัวใจ ปอด และสมอง
- แบบทดสอบ 8 ข้อ พร้อมเฉลยและคะแนนในหน้าจอ
- หน้าจอรองรับโทรศัพท์และคอมพิวเตอร์

## ข้อจำกัดของอุปกรณ์
การวางโมเดลบนพื้น/โต๊ะผ่าน Scene Viewer ต้องใช้อุปกรณ์ที่รองรับ ARCore และบริการ Google Play Services for AR ที่เหมาะสม หากโทรศัพท์ไม่รองรับ ปุ่ม AR อาจไม่ปรากฏหรือเปิดได้เฉพาะโหมด 3 มิติ เว็บไซต์ยังคงแสดงโมเดลให้หมุนและซูมได้

Image AR ใช้ MindAR image tracking ไม่ต้องพึ่ง ARCore แต่ต้องใช้ภาพเป้าหมายที่ผ่านการ Compile เป็นไฟล์ `.mind` ก่อน และต้องอนุญาตการใช้กล้องผ่าน HTTPS

## ขั้นตอนติดตั้งบน GitHub
1. เปิด repository: https://github.com/mudee-sudo/mayo-ar
2. ดาวน์โหลด ZIP ชุดนี้และแตกไฟล์ในคอมพิวเตอร์
3. ใน repository เลือก **Add file > Upload files**
4. อัปโหลด `index.html`, โฟลเดอร์ `css`, `js`, `targets` และ `README.md` จากชุดนี้ (ลากทั้งโฟลเดอร์ได้ในหน้าต่าง Upload files)
5. อย่าลบหรือเปลี่ยนชื่อ `heart.glb` เดิม และตรวจว่ามันอยู่ระดับเดียวกับ `index.html`
6. กด **Commit changes**
7. เปิด **Settings > Pages** ตรวจว่า Source เป็น Deploy from a branch, Branch เป็น `main`, Folder เป็น `/(root)` แล้ว Save (ถ้าตั้งไว้แล้วไม่ต้องเปลี่ยน)
8. รอ Deploy แล้วเปิด https://mudee-sudo.github.io/mayo-ar/

## เปิด Image AR ให้ใช้งาน
ไฟล์ `targets/heart.mind` เป็นไฟล์ที่ต้องสร้างจากภาพเป้าหมายจริงก่อน (ไม่ได้สร้างสำเร็จโดยอัตโนมัติใน ZIP นี้)

1. ใช้ภาพบัตรหัวใจที่มีรายละเอียดชัดเจน คอนทราสต์ดี ไม่เป็นพื้นเรียบหรือมีพื้นที่ว่างมาก
2. เปิด MindAR Image Targets Compiler จากลิงก์ในเอกสารทางการ: https://hiukim.github.io/mind-ar-js-doc/quick-start/compile/
3. เปิดเครื่องมือ **Image Targets Compiler** ที่ลิงก์จากหน้านั้น
4. อัปโหลดภาพบัตรหัวใจ แล้วกด Start
5. เมื่อประมวลผลเสร็จ กด Download เพื่อรับไฟล์ `.mind`
6. เปลี่ยนชื่อไฟล์ที่ดาวน์โหลดเป็น `heart.mind`
7. อัปโหลดไฟล์ไปที่โฟลเดอร์ `targets/` ใน GitHub
8. พิมพ์ภาพบัตรภาพเดียวกันออกมา หรือเปิดบนอีกหน้าจอ แล้วใช้โทรศัพท์เปิดเว็บไซต์ผ่าน Chrome > AR อวัยวะ > เปิดกล้องสแกนภาพ

**สำคัญ:** ภาพที่ใช้สแกนต้องเป็นภาพเดียวกับภาพที่นำไป Compile ทุกประการ หากเปลี่ยนภาพ ต้อง Compile ใหม่และอัปโหลดไฟล์ `.mind` ใหม่

## เพิ่มโมเดลปอดและสมองภายหลัง
- วางไฟล์ `lungs.glb` และ `brain.glb` ไว้ระดับเดียวกับ `heart.glb`
- ปรับรายการอวัยวะใน `index.html` และ JavaScript ให้ชี้ไปยังไฟล์ใหม่
- ควรตรวจสิทธิ์การใช้งาน/ใบอนุญาตของโมเดล 3 มิติทุกไฟล์ก่อนเผยแพร่

## ทดสอบ
- ใช้ Chrome บน Android และเปิดผ่าน URL HTTPS ของ GitHub Pages
- อนุญาต Camera เมื่อใช้ Image AR
- ทดสอบโมเดล 3 มิติด้วยการลากเพื่อหมุน และถ่างสองนิ้วเพื่อซูม
- ทดสอบแบบทดสอบและตรวจว่าคะแนนแสดงหลังตอบครบ 8 ข้อ

## ขอบเขตของต้นแบบ
คะแนนแบบทดสอบในเวอร์ชันนี้แสดงเฉพาะในหน้าเว็บขณะใช้งาน ยังไม่มีระบบฐานข้อมูล/รายชื่อนักเรียน/บันทึกคะแนนถาวร หากต้องการเก็บผลคะแนนเป็นรายบุคคล ต้องเพิ่มระบบหลังบ้าน เช่น Google Apps Script และ Google Sheets พร้อมออกแบบการคุ้มครองข้อมูลผู้เรียน
